  • Input: PDF files in ./data/ folder
  • Processing: Extract, chunk, and embed using Nomic
  • Storage: Vectors and metadata stored in ChromaDB
  • Query: User query embedded and searched semantically

  • Output: Results displayed in web interface

Chunking Strategy:
  • Chunk Size: 1000 characters (optimal for embeddings and context)
  • Overlap: 200 characters (maintains context continuity)
  • Separators: ["\n\n", "\n", ". ", " ", ""] (preserves structure)
  • Embedding Dimension: 384 (Nomic Embed output)
  • Storage: Each chunk stored with source, index, and timestamp

Retrieval Process:
  • Query Embedding: User query converted to vector using Nomic Embed
  • Similarity Search: Cosine similarity computed against all stored vectors
  • Top-K Selection: Top-5 (configurable) most similar chunks retrieved
  • Context Building: Chunks formatted with source and similarity scores
  • LLM Prompting: Context + query sent to Groq API
  • Response Generation: Mixtral-8x7b generates contextualized answer
